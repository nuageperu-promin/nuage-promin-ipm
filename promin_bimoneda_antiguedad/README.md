# promin_bimoneda_antiguedad

Variante en dólares de «Cuenta por cobrar vencida» y «Cuenta por pagar vencida».
Se elige la variante desde el selector del propio reporte: (SOL) o (USD).
El saldo pendiente en USD es el saldo pendiente en soles por la proporción USD/soles del
movimiento (`account.move.line.nuage_balance_usd`, módulo `promin_bimoneda_pen_usd`).
